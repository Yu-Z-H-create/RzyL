# Dawu 插件 - 物理实验图片查询

本插件提供物理实验图片查询功能，支持精确匹配和 AI 模糊匹配。

## 目录结构

```
dawu/
├── __init__.py          # 主逻辑
├── config.py            # 配置文件
├── keywords.py          # 关键词定义
├── ai_match.py         # AI 模糊匹配
└── README.md           # 本文件
```

## 更新实验图片

### 图片存放位置

所有实验图片存放在：`src/asserts/dawu/`

### 图片命名规则

- **格式**：`{关键词}.jpg`
- **示例**：`Youngs_Modulus_of_Steel_Wire.jpg`
- **要求**：文件名必须与 `keywords.py` 中 `KEYWORDS` 字典的键完全一致

### 关键词配置

在 `keywords.py` 中定义关键词：

```python
KEYWORDS = {
    "关键词名称": ["别名1", "别名2", "别名3"],
    "Youngs_Modulus_of_Steel_Wire": ["杨氏模量", "钢丝", "弹性模量"],
}
```

**规则**：
- 键（key）：关键词名称，必须与图片文件名一致
- 值（value）：别名列表，支持多个别名

### 更新步骤

1. **准备图片**
   - 确保图片为 JPG 格式
   - 建议分辨率：1920x1080 或更高
   - 文件大小建议：小于 1MB

2. **命名图片**
   - 使用英文关键词作为文件名
   - 示例：`Youngs_Modulus_of_Steel_Wire.jpg`

3. **放置图片**
   - 将图片复制到 `src/asserts/dawu/` 目录
   - 确保文件名与关键词完全匹配

4. **配置关键词**
   - 在 `keywords.py` 中添加或修改关键词
   - 添加相关别名，方便用户查询和AI模糊匹配

5. **测试验证**
   - 重启机器人
   - 使用别名测试图片是否能正常显示

## 注意事项

### 文件命名

- **严格匹配**：图片文件名必须与关键词完全一致，区分大小写
- **使用英文**：关键词建议使用英文，避免中文路径问题
- **避免空格**：文件名中不要包含空格，使用下划线 `_` 代替

### 图片质量

- **清晰度**：确保图片清晰，文字可读
- **完整性**：图片应包含实验的关键信息
- **格式统一**：建议所有图片使用相同的尺寸和风格

### 关键词配置

- **别名丰富**：为每个实验添加多个常用别名
- **避免冲突**：不同实验的别名不要重复
- **语义准确**：别名应准确反映实验内容

### AI 匹配

- **别名影响**：AI 会根据别名进行模糊匹配
- **关键词列表**：AI 能够看到所有关键词和别名
- **快速响应**：AI 配置为快速响应，不会过度思考

## 示例

### 添加新实验

假设要添加"牛顿环实验"：

1. 准备图片，命名为 `Newtons_Rings.jpg`
2. 将图片放到 `src/asserts/dawu/` 目录
3. 在 `keywords.py` 中添加：

```python
KEYWORDS = {
    # ... 其他关键词 ...
    "Newtons_Rings": ["牛顿环", "干涉条纹", "等厚干涉"],
}
```

4. 重启机器人
5. 测试：`大雾1 牛顿环` 或 `大雾1 干涉条纹`

### 修改现有实验

如果要修改"杨氏模量"的别名：

1. 编辑 `keywords.py`：

```python
"Youngs_Modulus_of_Steel_Wire": ["杨氏模量", "钢丝", "弹性模量", "拉伸实验"],
```

2. 重启机器人
3. 测试新的别名

## 故障排查

### 图片不显示

- 检查文件名是否与关键词完全匹配
- 确认图片文件存在
- 检查图片格式是否为 JPG
- 查看机器人日志获取错误信息

### AI 匹配不准确

- 增加更多相关别名
- 确保别名能准确描述实验内容
- 检查 API 配置是否正确

### 关键词冲突

- 检查不同实验的别名是否重复
- 使用更具体的别名
- 避免使用过于通用的词汇

## 技术说明

### 精确匹配

系统首先进行精确匹配，检查用户输入是否包含关键词的别名。

### AI 模糊匹配

精确匹配失败时，调用 AI 进行模糊匹配。AI 会根据用户输入和关键词列表，返回最相关的实验。

### 图片路径

图片路径通过 `config.py` 中的 `get_image_path()` 函数生成：

```python
def get_image_path(keyword: str) -> Path:
    return Path.cwd() / "src" / "asserts" / "dawu" / f"{keyword}.jpg"
```
